# SantéMada — Plateforme nationale de santé numérique

Projet de stage : une plateforme web pour centraliser la gestion des
services de santé à Madagascar.

## Fonctionnalités prévues
- Recherche de professionnels et d'établissements de santé
- Prise de rendez-vous
- Espaces patient, professionnel et administrateur

## Technologies
- Frontend : HTML, CSS, JavaScript, puis React
- Backend : Node.js, Express.js
- Base de données : MySQL
